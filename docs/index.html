Workflow

Intelligent 7-Step Pipeline

From issue to pull request in minutes. Each step is powered by state-of-the-art AI models and retrieval-augmented generation.

01
🔎

Issue Fetching

Automatically fetches issue details from GitHub including title, description, labels, and author metadata via the PyGithub API.

02
🧠

Issue Interpretation

GPT-4o analyzes the issue to extract a structured summary, classify the type (bug, feature, refactor), and identify affected areas.

03
📊

Codebase Indexing

Clones the repository, splits source files into chunks, generates vector embeddings, and stores them in a FAISS index.

04
🎯

Context Retrieval

Uses RAG-powered semantic search to find the most relevant code snippets from the indexed codebase for the specific issue.

05
🛠

Patch Generation

With issue context and relevant code, GPT-4o generates a clean unified diff patch following the repository's existing code style.

06
✅

AI Code Review

An AI reviewer evaluates the patch for correctness, security, performance, and edge cases, providing a quality score and verdict.

07
🚀

PR Creation

Creates a new branch, commits the patch, and opens a pull request referencing the original issue with the full AI review.

Capabilities

Key Features

Everything you need to automate your issue-to-PR workflow with AI.

💡

Intelligent Issue Understanding

Goes beyond keyword matching. The LLM deeply understands issue intent, classifies types, identifies affected areas, and generates targeted search queries for the codebase.

🗃

RAG-Powered Code Search

Embeds your entire codebase into a FAISS vector store for semantic search. Finds the most relevant code snippets even across large repositories with thousands of files.

🔧

Context-Aware Patches

Generates minimal, focused unified diff patches that follow your repository's existing code style and conventions. No unnecessary changes or refactoring.

🛡

Automated Code Review

Every patch is reviewed by an AI agent checking for correctness, security vulnerabilities, performance issues, and edge cases before the PR is created.

⚡

Webhook Automation

Set up the FastAPI webhook server and the entire pipeline triggers automatically whenever a new issue is opened in your repository. Zero manual intervention.

💻

CLI Interface

Full command-line interface to process specific issues, list open issues, or start the webhook server. Integrates seamlessly into any development workflow.

Quick Start

Get Started in Minutes

Set up GitFix AI and start resolving issues automatically.

1

Clone & Install

Clone the repository and install Python dependencies.

$ git clone https://github.com/Arnold-28/protothon.git
$ cd protothon
$ python -m venv venv && source venv/bin/activate
$ pip install -r requirements.txt
2

Configure Environment

Set up your API keys and repository target.

$ cp .env.example .env

# Edit .env with your keys:
OPENAI_API_KEY=sk-your-key-here
GITHUB_TOKEN=ghp_your-token-here
REPO_NAME=owner/repository
3

Run the Pipeline

Process an issue or start the webhook server.

# Process a specific issue
$ python main.py --issue 42

# Or start the webhook server
$ python main.py --server

# List open issues
$ python main.py --list-issues
